# 个性化美甲推荐 Demo 案例库

> 以下全部是合成案例，只用于演示检索、推荐和解释链路，不是真实顾客数据。

## 案例 A：短巧、偏丰润、高频键盘

手型画像：修长 31，纤细 37，掌宽 68，软润 61。用户偏好：低调、显白、日常通勤，长时间使用键盘。

推荐候选一：短椭圆裸粉细法式。理由是细法式提供纵向延伸，短椭圆保留键盘便利性，裸粉适合通勤。推荐候选二：中央光带的低闪猫眼，使用纵向光带增加修长感，避免满钻增加日常维护成本。

## 案例 B：修长、纤细、想要约会风格

手型画像：修长 82，纤细 79，掌宽 39，软润 47。用户偏好：温柔但不要过于素，用于约会和拍照。

推荐候选一：中短甲的红茶果冻渐变，通过中等对比增加镜头表现，避免过长尖甲进一步拉长。推荐候选二：珍珠光法式变体，仅在无名指或拇指使用局部装饰，保留精致感。

## 案例 C：掌宽感明显、想要高级感活动款

手型画像：修长 54，纤细 43，掌宽 81，软润 45。用户偏好：宴会、高级感、可接受中长甲。

推荐候选一：深酒红中长椭圆甲，以统一色调减少视觉切割，用一到两枚纵向金属线作为主元素。推荐候选二：深色磁石猫眼，光带保持纵向，装饰密度控制在中低水平。

## 案例 D：数据不足时的对话策略

已知：用户试穿评分 84，但没有明确场景和可接受甲长。顾问不应重复追问手型或要求重新上传手图，而应追问：主要用于通勤、校园还是约会；能否接受超过指腹的长度。得到回答后，在当前 Agent 状态中更新场景和长度偏好，再重排候选款式。
